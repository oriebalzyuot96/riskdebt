Where is your token saved?

It checks where tokens live

Flagged

  • localStorage / sessionStorage
  • document.cookie from JS
  • ?token= in URLs
  • console.log(token)
  • hard-coded JWT secret

Recommended

  • HttpOnly; Secure cookie
  • Authorization header
  • env var / secret manager
  • ${ENV} in MCP config
  • JWT validation on
